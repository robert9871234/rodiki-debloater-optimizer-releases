# RoDiKi Debloater & Optimizer - releases

Downloads of RoDiKi Debloater & Optimizer (a Windows 11 debloat and tweak tool). Only the finished downloads are here, no source code.

## Start it online (one command)

Open PowerShell and paste:

```powershell
irm https://github.com/robert9871234/rodiki-debloater-optimizer-releases/releases/latest/download/Start-Online.ps1 | iex
```

It downloads the newest release, checks its SHA-256 value, unpacks it and starts the tool. Nothing is installed. Windows asks for administrator rights (click Yes).

## Download manually

Go to the [latest release](https://github.com/robert9871234/rodiki-debloater-optimizer-releases/releases/latest), download the `.zip`, unpack it and run `Start.cmd`.
